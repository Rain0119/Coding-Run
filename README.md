# Coding Run

## 控制方式

| 操作 | 按鍵 |
|------|------|
| 向左移動 | <kbd>A</kbd> 或 <kbd>←</kbd> |
| 向右移動 | <kbd>D</kbd> 或 <kbd>→</kbd> |
| 重新開始 | 遊戲結束後點擊「重新開始」按鈕 |

## 遊戲規則

1. **躲避BUG** - BUG會從上方不斷下落
2. **難度升級** - 每達到 100 分時升級難度
   - 難度等級越高，障礙物移動速度越快
   - 障礙物出現頻率越高
3. **碰撞** - 與障礙物接觸時遊戲結束

## 數據保存

- 最高分會自動保存在瀏覽器的localStorage中
- 清除localStorage會重置最高分
- 每個瀏覽器和設備都有獨立的最高分記錄
