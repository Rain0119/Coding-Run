# 🏃 三軌無限奔跑遊戲

一款簡單有趣的瀏覽器三軌無限奔跑遊戲！躲避障礙物，獲得高分。

## 🎮 遊戲功能

✨ **核心特性：**
- **三軌道系統** - 在左、中、右三條軌道上移動
- **動態難度** - 難度隨著分數逐漸增加，速度和障礙物頻率上升
- **無限遊戲** - 持續奔跑直到碰撞障礙物
- **最高分記錄** - 使用瀏覽器本地存儲自動保存最高分
- **即時反饋** - 顯示當前分數、難度等級和最高分

## 🚀 如何開始

### 方法一：直接打開文件
1. 下載 `index.html` 文件
2. 在瀏覽器中直接打開該文件（雙擊或右鍵「用瀏覽器打開」）
3. 開始遊戲！

### 方法二：使用本地服務器（推薦）
如果你有 Python：
```bash
python -m http.server 8000
```
然後在瀏覽器打開：`http://localhost:8000`

如果你有 Node.js 和 http-server：
```bash
npx http-server
```

## 🎮 控制方式

| 操作 | 按鍵 |
|------|------|
| 向左移動 | <kbd>A</kbd> 或 <kbd>←</kbd> |
| 向右移動 | <kbd>D</kbd> 或 <kbd>→</kbd> |
| 重新開始 | 遊戲結束後點擊「重新開始」按鈕 |

## 📊 遊戲規則

1. **躲避障礙物** - 紅色方塊會從上方不斷下落
2. **獲得分數** - 每躲避一個障礙物獲得 **10 分**
3. **難度升級** - 每達到 100 分時升級難度
   - 難度等級越高，障礙物移動速度越快
   - 障礙物出現頻率越高
4. **碰撞失敗** - 與障礙物接觸時遊戲結束

## 📈 難度系統

| 分數範圍 | 難度等級 | 速度 | 出現頻率 |
|---------|--------|------|--------|
| 0-99 | 1 | 基礎 | 低 |
| 100-199 | 2 | 稍快 | 中 |
| 200-299 | 3 | 更快 | 中等偏高 |
| 300+ | 4+ | 很快 | 很高 |

## 💾 數據保存

- 最高分會自動保存在瀏覽器的本地存儲中
- 清除瀏覽器數據會重置最高分
- 每個瀏覽器和設備都有獨立的最高分記錄

## 🎨 遊戲畫面

- **玩家角色** - 紅色小方塊（帶眼睛）
- **軌道線** - 白色虛線標示三條軌道
- **障礙物** - 紅色方塊從上方下落
- **背景** - 漸變色彩的遊戲場景
